# Workstream 2: Crop Health Diagnosis

**Team members:** Anny and Gabin.

This workstream covers image-based crop health diagnosis, image preprocessing, computer vision experiments, model evaluation, and prediction. Use `data/` for permitted image dataset documentation, `notebooks/` for exploration, `src/` for reusable processing and modeling, `tests/` for validation, and `reports/` for findings. No trained diagnostic model is implied by this structure.
