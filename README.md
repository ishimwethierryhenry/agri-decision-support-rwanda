# Team 8 - Agriculture Decision Support for Rwanda

## Project Overview

This repository contains the shared codebase for Team 8's CMU-Africa practicum project. The project focuses on data-driven agricultural decision support for smallholder agricultural stakeholders in Rwanda.

The repository is divided into two main technical workstreams, supported by shared integration and reporting components.

## Workstream 1: Crop Recommendation

**Team members:** Thierry Henry and Arsene

This workstream focuses on data preparation, machine learning experiments, crop recommendation, and the supporting evaluation and reporting.

Main folder: `01-crop-recommendation/`

## Workstream 2: Crop Health Diagnosis

**Team members:** Anny and Gabin

This workstream focuses on crop image data, image processing, computer vision models, crop health prediction, and model evaluation.

Main folder: `02-crop-health/`

## Shared Components

The `03-shared/` folder contains the dashboard, APIs, integration work, and shared tests.

The `04-data-reporting/` folder contains the data catalogue, data quality findings, experiment records, and report drafts.

The `docs/` folder contains the overall architecture, API contracts, and project planning documents.

## Team Workflow

- Coordinate tasks using the team's shared tracker and GitHub Issues.
- Work in separate branches and submit pull requests for review.
- Document datasets, experiments, evaluation results, and limitations.
- Do not commit credentials, secrets, or restricted datasets.
- Keep the repository aligned with the approved Statement of Work and project roadmap.

## Project Status

The repository structure is being established. Implementation, data analysis, evaluation, and integration will progress across both workstreams.
